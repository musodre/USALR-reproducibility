# TMD provenance note

`02_track_physical_tmd_branch.py` (historical name `9.py`) consumes:

`thermo_response/TMD_local_quadratic/TMD_local_quadratic_all.dat`

The available comparison showed that this file is **not identical** to
`TMD_all_pressures_validation.dat` generated by `find_alltmd_points.py`.

Example differences:

- at P*=0.20, the validation file rejects the state, whereas the local-quadratic
  table contains a validated maximum near T*=0.196;
- at P*=0.30, the two files report different TMD temperatures;
- at P*=0.325, the classifications differ.

Therefore the historical intermediate file must be preserved with the final
archival data package unless its exact generator is recovered or independently
reconstructed and validated.
